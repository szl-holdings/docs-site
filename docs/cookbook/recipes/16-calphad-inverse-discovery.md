## Intended workflow

1. Pin thermodynamic input data and database/license identity.
2. Declare phases, composition bounds, temperature/pressure range, and objective.
3. Run a named solver/version with deterministic seeds and preserve logs.
4. Validate candidates against held-out or independent evidence.
5. Label predictions **MODELED** until measured.
6. Verify any receipt separately from the numerical result.

An inverse solution, even if numerically converged, is not a discovered material or production
guarantee. Current executable/runtime state: **UNAVAILABLE**.
